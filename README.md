Qt_Remote (远程控制系统)
📖 项目简介
本项目是一个基于 C++17 和 Qt6 开发的轻量级远程桌面控制与文件管理系统。项目最初基于 MFC 架构，后经过重构全面迁移至 Qt 框架，实现了跨网络的高效远程控制。系统采用 Client/Server 架构，内置自定义的 TCP 应用层协议，具备较高的稳定性和响应速度。

✨ 核心功能
🖥️ 远程桌面监控与控制

实时抓取被控端屏幕，采用 JPG 压缩降低网络带宽压力。

支持远程鼠标事件同步（移动、左/右/中键单击与双击、滚轮滚动），通过计算相对坐标精准映射到服务端。

📁 远程文件管理

获取被控端磁盘驱动器列表及目录层级信息。

支持远程文件的浏览、打开运行、删除（支持级联删除文件夹）以及分块下载至本地。

🔒 安全与锁机控制

提供远程锁机功能，全屏置顶并隐藏任务栏，通过 ClipCursor 限制鼠标活动范围。

屏蔽 Alt+F4 关闭窗口，支持服务端本地通过 Insert 键紧急解锁。

🛠️ 技术栈
开发语言: C++17

GUI & 网络框架: Qt 6 (Widgets, Network)

构建工具: CMake 3.16+

系统 API: Windows API (用于鼠标输入注入 SendInput、系统目录遍历等)

🏗️ 项目结构
项目分为三个主要模块：

common/: 公共网络模块。封装了基于 TCP 的通信协议头、指令枚举、以及 PacketStreamParser 和 PacketStreamWriter 用于处理 TCP 粘包与分包问题。

server/: 被控端程序。负责监听指定端口，接收指令并调用系统 API 执行锁机、截屏、文件读写等操作。

client/: 主控端程序。包含可视化的文件管理器 (FileManagerWidget) 和 远程桌面渲染视图 (RemoteDesktopWidget)。

🚀 编译与运行
确保已安装 Qt 6 和 CMake。

克隆项目后，使用 Qt Creator 或 CLion 打开根目录的 CMakeLists.txt。

编译生成 client.exe 和 server.exe。

运行测试：

启动 server.exe，设置监听端口（默认 5555）并点击“启动监听”。

启动 client.exe，输入服务端的 IP 地址和端口号，点击“连接”。

连接成功后，即可使用功能面板上的“文件管理”和“远程桌面”功能。
